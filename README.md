# hxyfront-62013 木结构榫卯构件测绘

源提示词编号：8

开发一个古建筑木结构榫卯构件测绘前端项目，测绘人员可以录入建筑名称、构件编号、木材种类、榫卯类型、截面尺寸、病害位置、变形情况和修缮建议。页面需要有构件清单、榫卯类型筛选、尺寸记录表、病害标记图和单栋建筑的构件关系视图。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62013

## 病害标记图业务模块

- `src/business/markerTransform.ts` — **标记换算**（纯函数）：像素点击 → 长宽百分比 → 毫米换算；同构件间距 < 构件长度 2% 自动合并（中点、等级取高、来源留痕）；越界/缺等级判定；截面尺寸改动后毫米位置保持、百分比按新尺寸重算并追加只读留档；修缮建议准入校验。
- `src/business/repository.ts` — **数据持久化**：localStorage 版本化存取（`hxyfront-62013:survey:v1`，损坏数据回退示例）与可订阅 store，提交即落盘，刷新/重开后清单、标记图、关系图一致。
- `src/business/surveyController.ts` — **界面操作**：落标/合并、标记补录与校正、构件与截面维护、修缮建议生成的全部编排，视图层只读快照。

规则：标记按百分比存储，窗口缩放位置不变；越界或缺等级只能待校正，不能带着问题标记生成修缮建议；尺寸改动或标记变更后旧建议作废。
